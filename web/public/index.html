Your Git history,
as a mountain range.

Every mountain is a folder and its height is the code it holds. The range grows commit by commit: added lines raise it, deleted lines erode it, and summits left alone for a long time gather snow. Put it in your README with one line of Markdown.

Try your repository

Add it to your README:

Public GitHub repositories up to 300 MB and 15,000 mainline commits. Images refresh once a day. The first drawing takes a minute or two while the free server wakes up.

How to read it

Mountains
Folders. The largest stands in the middle; strata picks the folder depth that gives at least four.
Height
Lines of code, on a log scale fixed to the largest size in the whole history.
Snow
Very tall summits, and those nobody has touched for a sixth of the history.
Headlines
Tags, big cleanups, restructures, quiet months, line milestones and new core contributors.

Other ways to use it

In your terminal

Watch it grow, pause and rewind. Works on any repository, local or remote.

go install github.com/umuttopalak/strata/cmd/strata@latest
strata                         # this repository
strata github.com/owner/repo   # any public one

Or download a binary from the releases.

With GitHub Actions

No size limits, private repositories, and a fresh image on every push.

- uses: actions/checkout@v7
  with:
    fetch-depth: 0
- uses: umuttopalak/strata@main
  with:
    branch: output

See the README for the full workflow.
